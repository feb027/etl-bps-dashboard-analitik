# Dashboard Specification — Fase 6

## Principle

Dashboard menampilkan data nyata saja. Semua angka, grafik, ranking, tabel, narasi, dan footer evidence harus berasal dari SQLite lokal atau artifact ETL yang sudah ada. Tidak ada dummy chart/table.

## Static Stack

- GitHub Pages static site.
- Vanilla HTML/CSS/JS modular.
- ECharts via CDN for chart rendering.
- No React, Vite, bundler, atau build step.

## Data Source

Generated by:

```bash
python3 scripts/generate_dashboard_data.py
```

Default database path:

```text
data/database/bps_etl.sqlite
```

If the database is missing, the generator fails with:

```bash
python3 scripts/run_etl.py --phase load --mode quick
```

## JSON Contract

`dashboard/data/dashboard-data.json` includes:

- `project`: title, status, `current_phase = "6 — Dashboard"`, generated timestamp, and Fase 6 review status from `docs/reviews/REVIEW_phase6_dashboard.md`.
- `summary`: indicator, region, year, fact row counts, and latest ETL run id.
- `filters`: indicator choices, year choices, source domains, ranking modes.
- `indicators`, `years`, `regions`: compact dimensions from SQLite.
- `series.trend`: indicator trend points by year from real fact rows.
- `rankings.top`, `rankings.bottom`, `rankings.change`: real regional averages and deltas.
- `table_rows`: compact joined rows from `fact_statistik`.
- `narrative_seed`: extrema and change statistics for honest client-side insight copy.
- `evidence`: database counts, source paths, run id, artifacts, and review references.
- `quality`: `no_dummy_data = true`, duplicate/missing-value notes, and aggregation caveats.
- `design_metrics`: legacy phase metrics plus Fase 6 chart/table counts.

## Aggregation Rule

BPS fact rows can include turunannya, for example perkotaan/perdesaan or semester/month labels. The dashboard does not invent a national row. Trend and ranking values are labeled as averages across available fact rows for the selected indicator, year, and region.

## UI Sections

1. Editorial hero with evidence ribbon.
2. Sticky atlas controls for indicator, year, region search, and ranking mode.
3. Main trend chart.
4. Narrative insight generated from `narrative_seed`.
5. Ranking chart.
6. Searchable/sortable detail table.
7. Evidence footer with DB counts, run id, artifacts, and quality flags.

## Accessibility and Fallbacks

- `lang="id"` remains set.
- Native form controls are labeled.
- Chart regions include `role="img"` and accessible labels.
- If ECharts CDN fails, fallback text/table renders in the chart section.
- Focus states are visible.
- Motion is subtle, under 300ms, and respects `prefers-reduced-motion`.
