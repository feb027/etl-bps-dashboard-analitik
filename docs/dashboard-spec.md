# Dashboard Specification

## Principle

Dashboard must show real data only. Empty state is allowed; dummy chart/table is not allowed.

## Data Source

```text
dashboard/data/dashboard-data.json
```

Generated by:

```bash
python scripts/generate_dashboard_data.py
```

## Sections

1. Project status and ETL summary.
2. Data coverage: indicators, regions, years, records.
3. Trend chart per indicator/year.
4. Regional comparison.
5. Data quality summary.
6. Methodology card.

## Empty State

If `record_count == 0`, render:

```text
Data statistik belum tersedia. Jalankan ETL setelah Fase 1–5 selesai.
```

No placeholder chart values.
